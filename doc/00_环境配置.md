# 在 H20 上配置训练环境

准备一台能用 `nvidia-smi` 看到 H20 的 Linux 机器，安装好 Conda，把完整的 `skill_rl_train/` 复制过去。**以下所有教程都在项目根目录执行**，也就是同时看得到 `EasyR1/`、`env/` 和 `scripts/` 的目录。

## 1. 新建独立的 Conda 环境

```bash
conda create -n skill-rl python=3.11 pip -y
conda activate skill-rl
python --version
```

应显示 Python 3.11.x。后面的训练依赖直接装进 `skill-rl`，这里可以跳过另建虚拟环境的 `setup.sh train`。[Conda 环境说明](https://docs.conda.io/projects/conda/en/stable/user-guide/tasks/manage-environments.html)

## 2. 安装与项目匹配的训练依赖

```bash
python -m pip install --upgrade pip setuptools wheel
python -m pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu124
python -m pip install -r env/train.txt -c env/easyr1-h20-constraints.txt
python -m pip install --no-deps -e ./EasyR1 -e .
```

| 组件            | 本项目 H20 配置                                                  |
| --------------- | ---------------------------------------------------------------- |
| GPU 运行时      | PyTorch 2.6.0，CUDA 12.4 构建，原生 BF16                         |
| 模型与 LoRA     | Transformers 4.57.6，PEFT 0.19.1，Accelerate 1.10.0              |
| EasyR1 训练依赖 | 随项目的 EasyR1 源码，Ray 2.46.0，TensorDict 0.7.2，NumPy 1.26.4 |

这里用 Transformers 对候选动作采样，复用 EasyR1 的训练算子。最后一行的 `--no-deps` 保留上一步装好的组合，首训无需额外安装 vLLM 或编译 FlashAttention。[项目版本约束](../env/easyr1-h20-constraints.txt) · [PyTorch 官方 cu124 安装说明](https://pytorch.org/get-started/previous-versions/#v260)

## 3. 指定本地模型，检查一张卡

把 Hugging Face 格式的 Qwen3-8B 放在 `models/Qwen3-8B/`，或将下面的路径改成已有模型的绝对路径。目录应含 `config.json`、tokenizer 文件、chat template 和全部 safetensors 权重分片。**新开终端时，回到项目根目录，重新执行下面三行环境设置。**

```bash
conda activate skill-rl
export SKILL_RSI_PYTHON="$CONDA_PREFIX/bin/python"
export SKILL_RL_MODEL="$PWD/models/Qwen3-8B"
```

```bash
CUDA_VISIBLE_DEVICES=0 python -m skill_rsi_rl.preflight \
  --expected-gpus 1 --backend easyr1 --model "$SKILL_RL_MODEL"
```

看到 `"ready": true` 就可以开始。若为 `false`，在 `checks` 中找失败项。`cuda` 显示可见卡数、型号和原生 BF16 支持，`checkpoint` 指出缺失的模型文件，`backend` 显示 EasyR1 实际加载的位置。
