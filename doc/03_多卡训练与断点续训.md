# 多张 H20 训练，以及从 checkpoint 续训

适合已有训练 replay 的场景。先完成[环境配置](00_环境配置.md)，并在[离线教程](02_用已有数据做离线训练.md)中校验 train/dev。多卡入口用 PyTorch DDP，每张卡各放一份模型，多卡分担不同数据组的计算。

## 1. 从两张 H20 启动

下面直接复用[单卡例子](01_单卡首次训练.md)产出的 replay，在新目录开始一次双卡实验。将 `DATA` 换成自己的 replay 目录即可。

```bash
DATA=runs/v2-smoke
OUT=runs/v2-2h20-train
export CUDA_VISIBLE_DEVICES=0,1
export SKILL_RSI_NPROC_PER_NODE=2
python -m skill_rsi_rl.preflight --model "$SKILL_RL_MODEL" --backend easyr1 \
  --expected-gpus "$SKILL_RSI_NPROC_PER_NODE" --replay "$DATA/train.jsonl"
```

预检显示 `"ready": true` 后启动。脚本名中的 `8h20` 是默认卡数，上面的环境变量将进程数设为 2。

```bash
./scripts/launch_8h20.sh --replay "$DATA/train.jsonl" --output "$OUT" \
  --per-device-batch-size 1 --epochs 1
```

使用八张卡时，将可见设备改为 `0,1,2,3,4,5,6,7`、进程数改为 `8`，并选新的 `OUT`。每卡 batch 为 1 时，一次完整更新共使用 8 个状态组。首个 checkpoint 在 `$OUT/checkpoint-0001/`，留出评测可直接使用[离线教程第 3 步](02_用已有数据做离线训练.md#3-比较训练前后的学生)，把 `--adapter` 改为这个路径。

## 2. 在原实验上从第 1 轮续到第 2 轮

沿用刚才的卡数、数据、模型和训练参数。把 `--epochs` 设为期望的**总轮数**，`--resume-from` 指向含 LoRA 和 `training_state.pt` 的完整目录。

```bash
./scripts/launch_8h20.sh --replay "$DATA/train.jsonl" --output "$OUT" \
  --per-device-batch-size 1 --epochs 2 --resume-from "$OUT/checkpoint-0001"
```

完成后会出现 `$OUT/checkpoint-0002/`。如果要续的是**单卡 v2 首训**，其每卡 batch 为 4，使用对应的单卡命令即可。

```bash
CUDA_VISIBLE_DEVICES=0 python -m skill_rsi_rl.train \
  --backend easyr1 --model "$SKILL_RL_MODEL" --device cuda --dtype bf16 \
  --replay runs/v2-smoke/train.jsonl --output runs/v2-smoke/train \
  --per-device-batch-size 4 --epochs 2 --resume-from runs/v2-smoke/train/checkpoint-0001
```

若要换数据或卡数开展新实验，用新输出目录和 `--init-adapter` 载入已有 LoRA；新实验会重新建立优化器。
