# 用已有数据做离线训练

先完成[环境配置](00_环境配置.md)。在项目根目录按数据格式选一个入口，接着执行第 2、3 步。离线训练从固定数据更新学生，更新期间无需调用原生 harness。

## 1. 选你的数据入口

**A. 已有 `train.jsonl` 和 `dev.jsonl`。** 如果刚完成[单卡首训](01_单卡首次训练.md)，直接使用下面的目录。换成自己的数据时，两份文件应符合本项目 replay 格式，包含候选动作、采样时的行为概率和奖励。

```bash
DATA=runs/v2-smoke
```

**B. 只有分支评分文件 `scored.json`。** 各准备一份 train 和 dev 的评分，目录布局见[原生分支采集](04_CL-Bench采集与在线训练.md#采集真实分支供离线训练)。先让冻结学生对候选采样，把动作概率和对应评分写成 replay。输出文件须使用新路径。

```bash
BRANCHES=runs/poker-branches
DATA=runs/poker-replay
mkdir -p "$DATA"
for split in train dev; do
  CUDA_VISIBLE_DEVICES=0 python -m skill_rsi_rl.collect sample \
    --split "$split" --replay-spec "$BRANCHES/$split/scored.json" \
    --model "$SKILL_RL_MODEL" --device cuda:0 --dtype bfloat16 \
    --samples-per-state 64 --temperature 1.5 --uniform-mix 0.35 \
    --output "$DATA/$split.jsonl"
done
```

## 2. 校验数据，训练一轮

```bash
python -m skill_rsi_rl.verify_replay --train "$DATA/train.jsonl" --dev "$DATA/dev.jsonl"
```

确认命令成功，`split_overlap` 中三项均为 0，且训练集的 `eligible_grpo_groups` 大于 0。组内所有候选得分相同时，这一组无法告诉学生哪个动作更好。

```bash
OUT=runs/replay-lora
CUDA_VISIBLE_DEVICES=0 python -m skill_rsi_rl.train \
  --backend easyr1 --model "$SKILL_RL_MODEL" --device cuda --dtype bf16 \
  --replay "$DATA/train.jsonl" --output "$OUT/train" \
  --epochs 1 --per-device-batch-size 1
```

权重写在 `$OUT/train/checkpoint-0001/`。手头只有合格的 train replay 时，可以直接运行这条训练命令；有独立的 dev replay 后，再核对划分并做开发集评测。

## 3. 比较训练前后的学生

```bash
CUDA_VISIBLE_DEVICES=0 python -m skill_rsi_rl.dev_eval \
  --model "$SKILL_RL_MODEL" --device cuda:0 --adapter "$OUT/train/checkpoint-0001" \
  --train-replay "$DATA/train.jsonl" --replay "$DATA/dev.jsonl" \
  --output "$OUT/dev-score.json"
```

开发集每个状态要有全部候选的评分 `option_scores`，这样才能在同一批状态上比较两份策略。下一次评测请使用新的报告文件名。
